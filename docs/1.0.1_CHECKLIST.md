# Checklist 1.0.1 Deployment Readiness

## Código

- [ ] `npm run check`
- [ ] `npm run deployment:validate`
- [ ] `npm run build`
- [ ] `mvn -f backend/pom.xml clean verify`
- [ ] Playwright Chromium y Mobile Chrome aprobados

## Configuración

- [ ] `.env.production` fuera de Git y con permisos `600`
- [ ] `MARKETING_IMAGE_TAG` único
- [ ] `DB_USERNAME` aplicativo
- [ ] `DB_PASSWORD` rotada
- [ ] `IP_HASH_SALT` de 32 caracteres o más
- [ ] CORS limitado al endpoint HTTPS
- [ ] SMTP desactivado o completamente configurado

## Infraestructura

- [ ] Reverse proxy HTTPS disponible
- [ ] Puerto `8081` no publicado
- [ ] Oracle `1521` no publicado
- [ ] Health `/health` y readiness aprobados
- [ ] Rotación de logs verificada
- [ ] Respaldo `MKT_*` probado
- [ ] Rollback probado con una imagen anterior
